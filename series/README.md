# series/ — серіали (зона Claude A)

Контент, з якого фабрика робить серії. Медіа тут немає: лише текст і маніфести.

```
series/<slug>/
  bible.md                 # логлайн, жанр, тон, світ, регіон/акцент, правила, арка сезону
  characters/<імʼя>.md     # зовнішність, характер, мова, голос (voice_id)
  refs.yaml                # маніфест затверджених референсів (шляхи в R2, хеші)
  episodes/E01/outline.md  # план серії + позначка хука для тизера
```

Як робити серію — `docs/PLAYBOOK.md`.
