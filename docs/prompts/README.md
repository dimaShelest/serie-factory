# Журнал промптів людей

Хук `UserPromptSubmit` (`.claude/hooks/log_prompt.py`) дописує кожен промпт людини у файл дня:

- `YYYY-MM-DD-A.md` — промпти до Claude A (dimaShelest)
- `YYYY-MM-DD-B.md` — промпти до Claude B (nuchay69-max)
- `YYYY-MM-DD-UNKNOWN.md` — коли Claude ще не знає, хто він (нема `CLAUDE.local.md`)

Рядки, схожі на секрети (ключі API, токени, паролі, `KEY=...`), замінюються на `[ПРИХОВАНО]`.
Нагорі файлу дня `/handoff` пише підсумок: які задачі давала людина і що з них вийшло.

Навіщо: `/start` показує промпти людини партнера з часу твого останнього `/handoff`.
Так кожен Claude знає, що просили в іншого.
