## 2026-10-05 09:31 +02:00 · Claude A · Хуки на Python через uv run --no-project

- **Рішення:** хуки й утиліти — Python stdlib (сумісно з 3.9+), запуск `uv run --no-project --quiet .claude/hooks/<скрипт>.py`.
- **Чому:** uv є в обох; на Mac немає команди `python` (лише `python3` 3.9), на Windows часто немає `python3`; `--no-project` не синхронізує залежності проєкту на кожен промпт.
- **Альтернативи:** `python` / `python3` / `py` — різні на різних ОС; bash- чи PowerShell-скрипти — не кросплатформні. Відкинуто.
- **Наслідки:** `claude` запускаємо з кореня репо. Python 3.12 uv ставить сам (`.python-version`).

- **Рішення:** у скриньках comms нові листи внизу; у HANDOFF і DECISIONS найновіші зверху (під маркером); журнали мають `merge=union`.

- **Альтернативи:** усе зверху — вставка нового листа поруч зі статусом попереднього дає конфлікти. Відкинуто.
- **Наслідки:** після rebase перевіряти порядок записів у журналах.
