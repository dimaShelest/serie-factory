## 0. Нова історія

Тека `series/<slug>/` (приклад — `series/la-garganta/`):
1. `bible.yaml` — логлайн, жанр, місце дії й акцент, **правила світу**, персонажі з **візуальною ДНК**
   (3–4 незмінні ознаки), голоси, локації, табу, ризики.
2. `story.md` — 4 частини бітами з мітками (розділ 3).
3. `clues.md` — ланцюжок підказок для детективу: що посіяно, де, що означає, де розкрито.
4. Референси персонажів і локацій (етап refs) → людина затверджує → маніфест у Git, файли в R2.

Відкладені історії лежать у `series/_archive/`.

## 2. Формат історії

- **Історія = 4 частини по 6–8 хв** (YouTube, 16:9), по 2 частини на тиждень.
- Після 4-ї частини — **Película completa** на 25–30 хв: частини підряд, без рекапів і заставок «Continuará…».
- До кожної частини — 1+ тизер 30–40 с (TikTok / Shorts, 9:16).

## 3. Мітки бітів

Їх ставимо в `series/<slug>/story.md`, а фабрика переносить у `script.json` / `shots.json`.
Перелік фіксований: нову мітку додаємо лише через `/decision` і лист Claude B, бо від неї залежать схеми.

| Мітка | Що це | Правила |
|---|---|---|
| `HOOK_OPEN` | Перші 5–15 с частини | Подія або питання одразу, без «розгону» і без рекапу перед ним. Одна на частину. |
| `MIDPOINT` | Поворот посередині частини | Змінює напрям або ставки: героям уже не повернутися до того, що було. Один на частину. |
| `SCREAMER` | Скрімер (jump scare) | 0,5–2 с: раптова поява чи рух + різкий звуковий удар. Перед ним 3–10 с тиші або наростання. Не більше 1–2 на частину. **У тизер — лише як `TEASER_CUT_BEFORE`** (обрив перед ударом). |
| `TEASER{n}_START` | Початок тизера n | n = 1, 2, … в межах частини. Звідси тизер має бути зрозумілим без контексту. |
| `TEASER{n}_CUT_BEFORE` | Тизер n обривається ПЕРЕД цим моментом | Кадр, репліка чи звук, які дали б відповідь. Від `_START` — 30–40 с. |
| `CLIFF` | Кліфхенгер у кінці частини | Частини 1–3 — нове питання, сильніше за закрите. Частина 4 — розв'язка + гачок на продовження. |

## 4. Правила хука для тизерів

- Перші 1–2 с — сильна емоція або питання, без «розгону».
- Обрив за мить до відповіді: репліка недоговорена, двері відчиняються, правда от-от відкриється.
- Фінальний кадр — заклик: «Parte completa en YouTube».
