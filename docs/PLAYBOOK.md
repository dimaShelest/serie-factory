## 1. Серія

| Крок | Хто | Що перевірити перед наступним |
|---|---|---|
| План серії `episodes/E0N/outline.md` | A + людина | конфлікт, поворот, **хук-обрив**; зв'язок з попередньою серією |
| script | фабрика | хронометраж 3–8 хв, жива іспанська, позначено момент для тизера |
| shots | фабрика | 3–10 с на шот, різноманіття планів, промпти без заборонених слів |
| refs / voice | фабрика | голоси персонажів упізнавані, вимова імен правильна |
| video → qc → repair | фабрика | обличчя консистентні, без артефактів; ліміт спроб |
| assemble | фабрика | ритм, гучність, субтитри |
| cut | фабрика | тизер 30–40 с, перші 2 с чіпляють, **обривається на хуку** |
| publish | людина підтверджує | назва/опис/теги ES, позначка AI, обкладинка |

## 2. Правила хука для тизерів

- Перші 1–2 с — сильна емоція або питання, без «розгону».
- Обрив за мить до відповіді: репліка недоговорена, двері відчиняються, правда от-от відкриється.
- Фінальний кадр — заклик: «Capítulo completo en YouTube».
