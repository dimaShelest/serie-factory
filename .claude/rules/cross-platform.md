# Кросплатформність (macOS/zsh ↔ Windows/PowerShell без WSL)

Кожен скрипт, хук і команда має працювати в обох партнерів.

- Шляхи — лише `pathlib.Path`. Ніяких `"dir/" + name` і `\\`. У Git і логах — `path.as_posix()`.
- Файли — завжди `encoding="utf-8"`. Читаючи файли, які могла записати людина, бери `encoding="utf-8-sig"`
  (PowerShell 5.1 пише з BOM). Записуй з `newline="\n"`.
- Вивід з українським текстом — спершу `sys.stdout.reconfigure(encoding="utf-8")`: консоль Windows не UTF-8.
- `subprocess.run([...])` — список аргументів, без `shell=True`, з `timeout=`.
- Хуки й утиліти — на Python, без bash/PowerShell-синтаксису. Виклик: `uv run --no-project <скрипт>`
  відносно кореня репо. Без `$VAR`, `&&`, `|`, перенаправлень у командах хуків.
- Тимчасові файли — `tempfile` або `.claude/tmp/`, не `/tmp`.
- Зовнішні інструменти (ffmpeg, gh, git) — шукай через `shutil.which`, дай зрозумілу помилку, якщо їх нема.
- Імена файлів: латиниця, цифри, `-`, `_`. Без `:` `?` `*` і пробілів: Windows їх не любить.
- Нова утиліта → тест у `tests/`, який не залежить від ОС.
