# Формати пам'яті

Час у журналах ставить `collab.py`: Claude не має годинника, тож дату й час не вигадуй — бери з `collab stamp`.
Формат часу всюди: `2026-10-05 14:30 +03:00`.

| Файл | Хто пише | Порядок | Як дописувати |
|---|---|---|---|
| `docs/HANDOFF.md` | обидва | найновіші **зверху** | `collab log handoff --title … --file …` |
| `docs/DECISIONS.md` | обидва | найновіші **зверху** | `collab log decision --title … --file …` |
| `docs/comms/to-X.md` | лише партнер X | нові **внизу** | `collab send …`; X лише міняє NEW → READ (`collab inbox --mark-read`) |
| `docs/prompts/YYYY-MM-DD-X.md` | хук Claude X | хронологічно | хук сам; підсумок — `collab prompt-summary` |
| `docs/STATUS.md`, `docs/MEMORY.md` | обидва | за розділами | редагуй руками, коротко |

Заголовки записів парсить `collab.py`, тож не змінюй їх руками:
- журнал: `## РРРР-ММ-ДД ГГ:ХХ ±ГГ:ХХ · Claude A · Назва`
- скринька: `## РРРР-ММ-ДД ГГ:ХХ ±ГГ:ХХ · від Claude A · NEW · Тема`

Правила:
- Чужі записи не редагуй і не видаляй. Твій запис помилковий → додай новий з виправленням.
- MEMORY.md — лише довгострокове: факт / домовленість / урок / «що не працює». Одна думка — один пункт з датою.
- STATUS.md — знімок «зараз». Зроблене переходить у HANDOFF, а зі STATUS прибирається через 1–2 сесії.
- Промпт для партнера самодостатній: що змінилось, що від нього потрібно, де дивитись (шляхи, PR, Issue).
