# fabrica/prompts/ — шаблони промптів генерації (зона Claude A)

По теці на етап: `script/`, `shots/`, `refs/`, `video/`, `qc/`, `cut/`.
Код фабрики (зона B) лише завантажує шаблони й підставляє змінні. Зміст і стиль — відповідальність A.

Домовленості (погодити з B, коли з'явиться каркас):
- шаблон = текстовий файл зі змінними `{{назва}}`; поруч — короткий опис входу й очікуваного виходу;
- зміна, що впливає на формат виходу (JSON-схему) → PR з рев'ю B;
- зміна стилю → запис у `docs/DECISIONS.md`.
